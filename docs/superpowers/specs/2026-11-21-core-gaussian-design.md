# Каркас и последовательная обработка изображений

Общий каркас в `main` позволяет пяти участникам начинать работу независимо. Ветка `feat/core-gaussian` добавляет файловый ввод и вывод, последовательный движок и Gaussian Blur. CLI, REST, CI, параллельные движки и бенчмарки принадлежат соответствующим участникам. Для ручной проверки предусмотрен отдельный запуск Gaussian Blur.

## Архитектура

Maven собирает Spring Boot 4.0 на Java 21. Пакет `com.team.imgproc` содержит общие контракты `ImageData`, `FilterStep`, `ImageFilter` и `ProcessingEngine`. Реестр получает фильтры через Spring и ищет их по `ImageFilter.name()`. `ImageData` хранит ARGB в порядке строк, защищает внутренний массив копиями и предоставляет чтение отдельного пикселя через `argbAt(index)`.

`ImageFileIO` читает регулярные файлы PNG, JPEG и BMP из одного каталога в стабильном порядке и пишет результаты по исходным именам. Символические ссылки пропускаются при перечислении, чтобы ввод и вывод не могли указать на один и тот же файл таким путём. Пустой каталог даёт пустой список. Повреждённый файл с поддерживаемым расширением вызывает ошибку с путём. Запись использует временный файл в каталоге назначения с последующей заменой целевого файла. PNG сохраняет прозрачность, JPEG и BMP сохраняют RGB.

`SequentialEngine` обрабатывает изображения в порядке входного списка. Для каждого шага фильтр читает предыдущий результат и записывает в свой массив. Пустая цепочка возвращает неизменные изображения. Параметр числа потоков должен быть положительным, последовательный движок выполняет работу в вызывающем потоке.

## Gaussian Blur

Двумерная свёртка проще в реализации, но выполняет порядка `W × H × K²` операций. Два глобальных прохода по целому изображению сокращают работу до `W × H × K`, но для параллельной версии потребовали бы отдельного барьера между проходами. Выбран сепарабельный фильтр в рамках имеющегося `applyRegion`: горизонтальный проход заполняет кольцевой буфер строк, нужных для вертикального прохода, включая соседние строки за границами полосы. Полосы независимы и пишут только в свои строки. Соседние полосы повторно вычисляют часть горизонтального прохода.

Края изображения продолжаются крайним пикселем. Ядро нормируется, результат округляется после вертикального прохода, альфа исходного пикселя сохраняется. Параметры `radius` и `sigma` по умолчанию равны 2 и 1.0. Радиус задаётся целым числом от 0 до 1024, чтобы ограничить размер ядра. σ задаётся конечным положительным числом.

## Проверка

На JDK 21 должны пройти сборка и тесты Spring DI, неизменяемости данных, порядка фильтров, JPEG/PNG/BMP, обработки ошибок и сопоставления Gaussian Blur с прямой 2D-свёрткой. Запуск `make run-seq` проходит полный цикл чтения, фильтрации и записи в другой каталог.
